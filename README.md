# Duomation — Animate Across Devices

**Duomation** is a browser-based 2D animation workstation that connects two devices into one synchronized animation workflow.

🌐 **Live App:** https://duomation.vercel.app/

## 🎨 What is Duomation?

Duomation lets you use two devices together while creating 2D animations.

- **Device A — Draw:** Create and edit animations using the drawing workspace and frame timeline.
- **Device B — Display:** Connect a second device as a dedicated live animation display.
- **Synchronized workflow:** Connect both devices through the built-in session and QR workflow.
- **Project management:** Create, open, import, and manage animation projects.
- **Export:** Export completed animations from the animation workspace.

The idea is simple:

> **Connect two devices. Animate across both screens.**

## ✨ Features

- 🎨 Frame-by-frame 2D animation
- 📱 Two-device animation workflow
- 🖥️ Dedicated second-device display

- 📥 JSON project import

- ☁️ Supabase cloud synchronization
- 📱 Responsive browser-based interface

## 🖥️ How It Works

1. Open **Duomation** on your primary device.
2. Create or open an animation project.
3. Open Duomation on a second device.
4. Select the display/connection option.
5. Connect the two devices using the provided QR/session workflow.
6. Draw and edit on the primary device.
7. Use the second device as a live animation display.

## 🚀 Why Duomation?

Traditional animation workflows can become cramped when everything has to fit on one screen.

Duomation explores a different approach: **use two devices together** so the drawing workspace and animation display can have their own screens.
